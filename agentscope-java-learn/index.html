把 AgentScope Java 2.0.4 学到「能自己写」

这不是官方文档的搬运，而是一套按初学者阅读顺序重排、每个结论都能回源码验证的教程。示例全部是 Java；每一章都有能复制运行的代码、端到端的运行过程、以及「你会撞到什么错」。

我该从哪儿开始

  1. 先花 12 分钟读「学习地图」
    它会告诉你三条主线怎么用、章节为什么是 THIS 顺序、以及没有 API Key 能学到哪一步。
    → 00 学习地图
  2. 装好环境（约 25 分钟）
    JDK 17 + Maven，两个依赖：agentscope-harness 与 agentscope-extensions-model-dashscope。
  3. 跑通第一个 Agent（约 35 分钟）
    → 02 第一个 Agent：30 行代码，跑完能看到工作区与状态存储两棵目录树，第二轮对话记得第一轮。
如果你只想最快验证「这框架能不能跑」

直接看 02 章的最小可跑那一段，复制、补两个 Maven 依赖、设一个 DASHSCOPE_API_KEY，其它全部先不管。

三条学习主线

① 跟做线：照抄能跑

  • 每章「最小可跑」小节都是完整 Java 文件，含 import
  • 代码里出现的每个 API 都能在附录 C 的速查表里查到出处
  • 目标是「先跑起来」，不追求先看懂

② 理解线：知道它在干什么

  • 每章「端到端一次运行发生了什么」把调用链摊开成时间轴
  • 关键机制给分层图：谁包着谁、状态在哪、什么时候落盘

③ 避坑线：出错时知道看哪儿

  • 每章「陷阱与窍门」按「你会看到 X → 因为 Y → 改成 Z」写
  • 附录 B 是报错速查，每条都能定位到源码抛出点
