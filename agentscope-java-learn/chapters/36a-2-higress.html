36A-2 · Higress MCP：工具搜索、注册与白名单

Higress 的重点不是「再接一个 MCP 客户端」，而是把工具治理留在网关，Agent 侧只拿一个已经鉴权、限流、可观测的工具面。 这一页把传输、构建、工具搜索、注册与白名单串起来，并给出「注册了但工具不可见」的排查顺序。

读完你能做到

  • 在 SSE 与 StreamableHTTP 之间按部署形态选择
  • 用 buildAsync() / buildSync() 正确构建客户端
  • 开启工具搜索并控制 Top K，避免一次把所有工具塞进上下文
  • 把客户端注册进 HigressToolkit，用 group / 白名单裁剪工具面
  • 分清哪些治理属于 Higress，哪些必须在 Java 侧做

传输：SSE 与 StreamableHTTP

builder 支持两种端点：sseEndpoint(...) 与 streamableHttpEndpoint(...)。 无状态 HTTP 流式场景优先 StreamableHTTP；需要长连接 SSE 时再用 SSE。 默认请求超时 120 秒，初始化超时 30 秒 HigressMcpClientBuilder.java:71-82。

端点适合注意
sseEndpoint网关提供长连接 SSE连接保持与重连由客户端负责
streamableHttpEndpoint无状态、可水平扩展每次请求独立，推荐优先

HigressMcpClientBuilder 没有 build()：只有返回 Mono 的 buildAsync() 和阻塞式 buildSync() HigressMcpClientBuilder.java:311 :357。 

HigressMcpClientWrapper client = HigressMcpClientBuilder
    .create("higress")
    .streamableHttpEndpoint("http://gateway/mcp-servers/union-tools-search")
    .buildSync();

工具搜索：默认关闭，开启后只回 Top K

工具搜索默认关闭。开启后 listTools() 不再返回全部工具，而是先调 x_higress_tool_search，只返回语义相关的 Top K，默认 10 个 HigressMcpClientWrapper.java:64 HigressMcpClientWrapper.java:156-204。 

HigressMcpClientWrapper client = HigressMcpClientBuilder
    .create("higress")
    .streamableHttpEndpoint(endpoint)
    .toolSearch("退款", 8)      // 查询词 + Top 8
    .buildSync();

Top K 太小会漏工具，太大又回到「工具太多」；按业务场景选 8–12 通常比默认 10 更可控。 工具搜索返回的结果会缓存到本地，后续 callTool 直接复用 HigressMcpClientWrapper.java:186-204。

注册：Toolkit 是最终生效点

客户端只是传输层；真正让 Agent 看到工具的是 HigressToolkit。 registerMcpClient 返回 Mono<Void>，注册成功后才会缓存客户端引用 HigressToolkit.java:99-120。 

HigressToolkit toolkit = new HigressToolkit();
toolkit.registerMcpClient(client).block();

toolkit.registration()
    .mcpClient(client)
    .enableTools(List.of("search-doc", "fetch-url"))
    .group("knowledge")
    .apply();

enableTools 是白名单，不是「额外推荐」；写了它，未列出的工具不会进入这个 group。 group 影响模型看到的工具分组，也影响后续按组启停。

治理边界：网关做什么，Java 做什么

事项Higress 网关Java / Agent 侧
鉴权统一校验调用方身份不重复实现 token 校验
限流 / 配额按路由或工具限流只处理 429 / 超时
工具路由决定请求落到哪个 MCP 服务只持有 endpoint
可观测网关侧日志、指标、链路记录工具名与业务结果
工具白名单可做粗粒度暴露用 enableTools 做 Agent 级裁剪

「网关做了鉴权」不等于「Agent 不需要权限」。工具能不能被这个 Agent 看见、调用前要不要人工确认，仍由 Toolkit 与权限引擎决定。

验收：工具真的进了 Toolkit

  1. 客户端可用
    toolkit.getHigressMcpClient() 非空。
  2. 工具可见
    listTools() 返回的名字与 enableTools 白名单一致。
  3. 调用成功
    让 Agent 调一个只读工具，拿到真实结果，而不是 schema 回显。
  4. 治理生效
    在网关侧关掉一个工具或触发限流，Agent 侧看到明确错误，而不是静默空结果。

失败边界

现象更可能的原因处理
编译失败用了 .build()改 buildSync() 或 buildAsync()
工具列表为空工具搜索查询词不匹配 / Top K 太小放宽查询词或调大 Top K
注册后仍不可见没 block() / 没走 apply()检查注册链与白名单
调用 401 / 403网关鉴权失败检查网关侧路由与凭据
调用超时请求超时 120 秒太短显式 timeout(...)
